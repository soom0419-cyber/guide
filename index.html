불량 접수 가이드

매장에서 불량을 발견한 순간부터 수선실로 보내기까지, 단계별로 정리했습니다.

1

접수 절차

  1. 매장 입고분 검수
    상품을 받는 즉시 불량 여부, 퀄리티, 구성품 유무 등을 검수합니다.
  2. 불량 내용 공유
    불량 발견 시 카카오톡 오픈채팅방에 공유합니다.
    불량 사진, 상세 내용, 가격택 사진은 필수로 첨부합니다.
  3. 접수
    전산에 수선 등록을 진행합니다.
    크레딧불량 매장으로 RT 반출 등록을 합니다.
    수선증을 작성해 상품에 부착합니다.
  4. 수선실 발송
    행낭을 이용해 실물을 수선실로 발송합니다.
2

수선등록 매뉴얼

12345678
  1. 상단 메뉴에서 고객관리 탭을 클릭합니다.
  2. 좌측 메뉴에서 수선등록 버튼을 클릭합니다.
  3. 접수일자를 선택합니다.
  4. 고객명에 "크레딧불량"을 입력합니다.
  5. 접수구분을 "크레딧불량"으로 선택합니다.
  6. 품번 / 색상 / 사이즈 등 상품정보를 입력합니다.
  7. 수선코드를 "기타"로 선택합니다.
  8. 접수내용에 불량 상세 내용을 작성합니다.
3

RT 반출 등록

1234
  1. 상단 메뉴에서 점간이동관리 탭을 클릭합니다.
  2. 좌측 메뉴에서 R/T 반출등록 버튼을 클릭합니다.
  3. 받는매장을 크레딧불량 매장(H9020)으로 등록합니다.
  4. 품번 / 색상 / 사이즈 등 상품정보를 입력합니다.
4

수기 수선증 작성

12
  1. 고객명에 "크레딧불량"을 기입합니다.
  2. 접수내용에는 불량 가이드의 카테고리 번호·항목명을 동일하게 적고, 불량 내용을 상세히 기입합니다. (예: 2. 제품 형태 - 바이저 플라스틱 형태)
